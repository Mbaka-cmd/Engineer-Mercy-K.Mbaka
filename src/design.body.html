Decisions in this portfolio

  • No framework, no build server. Plain HTML, CSS and JavaScript, with pages generated from one shared template so navigation and footer stay consistent.
  • No external fonts or icon libraries. System font stacks and inline SVG keep requests few and pages quick on slow connections.
  • Accessible navigation. The full-screen menu traps and returns keyboard focus, closes with Escape, locks background scrolling and marks the current page.
  • Reduced motion respected. Animations switch off for visitors who ask for it.
  • Real content only. Projects, statuses and technology levels are labelled honestly.
